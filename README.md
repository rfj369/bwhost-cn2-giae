## 下单前要知道的几件事

**退款政策**：新账户注册 30 天内可以申请一次无理由全额退款，条件是流量使用不超过 10%、购买总额低于 $100、购买次数少于 10 次，按账户注册时间算，申请后通常很快到账。想先买来测速的，这条是兜底。

**不会自动续费**。不管绑的是信用卡还是 PayPal，到期都不会自动扣款，需要手动续费或提前充值。流量用完也不会产生超额账单，VPS 暂停到下一个计费周期。怕忘续费的，提前在账户里留够余额即可。

**优惠码时效要自己验证**。搬瓦工历史上长期有全场 6.77% 的循环折扣码（结账页 Promotional Code 填入后点 Validate Code），但这类码会过期，2026 年中的检查显示当时已无固定可用的常规码。买的时候在结账页试一下当期代码，有效就填，没有就按原价走——别为了等码把想买的套餐等断货了。另外提醒一句：用优惠码购买的套餐，后续升级配置时折扣不一定保留。
